# WE Trip – תוכנית פיתוח (MVP → פיצ'רים מתקדמים)

## שלב 1 – תשתיות וחיבורי בסיס
- [ ] יצירת פרופיל משתמש (Firebase Auth + Firestore).
- [ ] CRUD למסלולים ידניים (ימים, נקודות interest, עלויות).
- [ ] העלאת מדיה ל-Firebase Storage.
- [ ] שמירת קטגוריות/תגיות ודירוגים.

## שלב 2 – חוויית משתמש רספונסיבית
- [ ] קומפוננטות ליום/נקודה/עלויות, תמיכה במובייל ודסקטופ.
- [ ] דף בית עם חיפוש וסינון (יעד, קטגוריה, דירוג, תקציב).
- [ ] עמוד פרופיל עם רשימת מסלולים, מועדפים וסטטיסטיקות.

## שלב 3 – אינטגרציות חיצוניות
- [ ] Speech-to-Text: הקלטת משתמש, שליחה לענן והצגת הטקסט.
- [ ] Gemini: רכישת מסלול מטקסט חופשי, אימות מול Google Maps.
- [ ] Google Maps Lists Import: העלאת רשימות interest, שיוך לימים ואזורים.

## שלב 4 – שכבת קהילה וניהול
- [ ] מועדפים, שיתופים, העתקת מסלול למשתמש אחר.
- [ ] דירוגים, טיפים, תגובות והמלצות.
- [ ] מערכת דיווחים ואזור אדמין לטיפול בתוכן פוגעני.

## שלב 5 – עלויות וסטטיסטיקות
- [ ] חלוקת עלויות לפי אזורים וקטגוריות (אוכל, לינה, תחבורה, אטרקציות).
- [ ] דשבורד סטטיסטיקות (מסלולים אהובים, יעדים חמים, מסלולים חדשים).
- [ ] יצוא/שיתוף (וואטסאפ, פייסבוק, קישור ישיר).

> הערה: בכל שלב יש להמשיך לתחזק את הקבצים בתיקיית `src/types` ואת מודולי Firebase/Integrations כך שישקפו את הרחבות הדאטה וה-API בפועל.
